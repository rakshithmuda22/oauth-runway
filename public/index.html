    How it works

    1. Research

    An agent searches and reads the provider's official developer docs, policies and changelogs, and cites every claim. Community sources are labelled as such.

    2. Test

    Code (not the model) hits the real authorize endpoint with an unregistered client, reads the OIDC metadata, opens the developer portal and re-checks every cited link. Those results appear under "Tested".

    3. Be honest

    Anything that couldn't be confirmed, conflicts between sources, or is an estimate is listed under "Uncertain". Each guide states its confidence.

    4. Split the work

    Every step is tagged as something an agent can do, something it can prepare for you, something only you can do (sign-in, legal, payment), or a wait on the provider.
